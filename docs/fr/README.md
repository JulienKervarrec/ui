# Parcours francais : ui (Base Chain Dashboard)

Lecture pedagogique du depot base/ui : le tableau de bord Next.js qui reunit le navigateur de snapshots Reth v2 et l explorateur/faucet Vibenet sous un seul shell, avec deux cibles de deploiement (externe et interne) issues d un seul code source.

Sommaire :

Chapitre 1 Presentation de base/ui. Chapitre 2 La matrice de deploiement, deploy.config.mjs et le middleware. Chapitre 3 Le navigateur de snapshots, signature SigV4 et reduction de manifeste. Chapitre 4 Vibenet, faucet et catalogue de demos. Chapitre 5 L index pour agents (llms.txt / AGENTS.md) et la CI. Chapitre 6 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
